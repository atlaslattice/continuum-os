# Continuum OS

**Continuum OS** is the public, forkable flagship index for the `atlaslattice` ecosystem. It organizes the active work into a discoverable starting point while preserving independent repository histories, licenses, forks, and upstream attribution.

> This repository is an **index and integration map**, not a mass import of third-party source trees. That approach keeps provenance and license obligations clear, avoids duplicating upstream projects, and lets contributors fork or follow each component independently.

## Start here

| Need | Repository | Why it matters |
|---|---|---|
| Universal Workspace CLI | [uws](https://github.com/atlaslattice/uws) | The public, forkable UWS flagship line. The repository exposes branches and tags as its version surface. |
| Platform architecture | [atlas-lattice-foundation](https://github.com/atlaslattice/atlas-lattice-foundation) | Foundation and governance materials. |
| Persistent memory API | [sheldonbrain-rag-api](https://github.com/atlaslattice/sheldonbrain-rag-api) | RAG API for the persistent-memory system. |
| Provider integrations | [atlas-lattice-providers](https://github.com/atlaslattice/atlas-lattice-providers) | Quarantined under the user’s AI-material policy; excluded from the active workspace. |

## UWS version access

The UWS line is preserved as a public repository with a public branch and tag history. Use the repository’s **Branches** and **Tags** selectors to browse, clone, or fork a specific version. No UWS branch, tag, commit, or upstream attribution is replaced by this index.

## Contribution and provenance

Each listed repository retains its own license, authorship, commit history, fork relationship, issue tracker, and contributor terms. Contributions should be made in the repository that owns the relevant code. If a cross-project change is proposed, open a tracking issue in this repository and link the affected repositories rather than copying code without its provenance.

## Roadmap

The next organizational step is to add a repository catalog with categories, a compatibility matrix, and a release map that links UWS tags to the projects that depend on them. Those additions will be made through ordinary pull requests to keep the flagship structure auditable.
