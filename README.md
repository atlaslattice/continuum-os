# Alexandria 2.0 / Continuum OS

**The public, forkable gateway to the Atlas Lattice knowledge corpus.**

Alexandria 2.0 treats GitHub as the durable public canon and receipt layer: source histories remain intact, upstream attribution remains intact, and evidence status is explicit. Continuum OS is the integration/index surface that makes the corpus navigable without flattening independent repositories into a monolith.

> **Nothing promotes itself.** A source can be measured, derived, simulated, proposed, hypothetical, historical, reference, or quarantined. Alexandria preserves what was published while making its present status computable.

## The Alexandria model

```text
SOURCE CORPUS
    ↓
PROVENANCE REGISTRY
    ↓
TYPED KNOWLEDGE GRAPH
    ↓
RETRIEVAL + 12×12 / PROJECT / EVIDENCE / TIMELINE VIEWS
```

The **12 Houses × 12 Spheres** lattice is a view over relationships, not a folder constraint. An artifact may participate in several spheres, projects, evidence states, locations, and timelines simultaneously.

## Public canon

The `atlaslattice` GitHub corpus is treated as the public source/receipt layer. Canon does **not** mean every statement in every repository is established fact. It means the source is preserved, attributable, versioned, and eligible to be addressed by Alexandria with explicit status.

Core evidence vocabulary:

`MEASURED` · `DERIVED` · `SIMULATED` · `PROPOSED` · `HYPOTHETICAL` · `HISTORICAL` · `REFERENCE` · `QUARANTINED`

See [CANON.md](CANON.md) for the invariants.

## Active ecosystem

The active public surface currently includes architecture and regenerative infrastructure, standards, interoperability/CLI work, persistent memory, governance, and research artifacts. Each project retains its own repository, history, license, issues, and contributor terms.

## Alexandria Library

The wider account also contains a large restored collection of upstream/reference repositories — languages, frameworks, AI systems, infrastructure tools, educational material, and other open-source projects.

These repositories are **Library material**, not claims of Atlas authorship. Their original licenses, histories, fork relationships, and upstream attribution remain authoritative.

This separation is intentional:

```text
ATLAS / ALEXANDRIA PROJECTS  → authored and developed work
ALEXANDRIA LIBRARY           → upstream/reference corpus
QUARANTINE                   → preserved but excluded from active canonical build/retrieval paths
```

## UWS version access

The UWS line remains a public repository with public branch/tag history. Browse its branches and tags for specific versions; this index does not replace or rewrite those histories.

## Quarantine

Quarantine is preservation with restricted canonical use, not deletion. Archived/quarantined repositories remain available for provenance and historical inspection but are excluded from active Alexandria build/retrieval projections until explicitly reviewed.

## Contribution and provenance

Contribute in the repository that owns the relevant source. Cross-project changes should link affected repositories rather than copying source trees without provenance.

Every listed repository retains its own license, authorship, commit history, fork relationship, issue tracker, and contributor terms.

## Roadmap

Alexandria 2.0 beta is moving toward:

1. machine-readable repository/artifact manifests;
2. claim-level evidence objects;
3. quantity/unit validation;
4. 12×12 House/Sphere graph projection;
5. project, provenance, timeline and infrastructure-node views;
6. reproducible semantic retrieval over approved graph projections;
7. public catalog and compatibility/release maps.

The objective is simple: **make a very large public corpus as legible, attributable, reproducible, and forkable as serious infrastructure software — without sacrificing the multidimensional Alexandria architecture.**
